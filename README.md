# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

给管风琴维护人员使用的音管调音记录前端项目：记录教堂/音乐厅名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注，页面包含音栓列表、调音偏差表、温湿度记录、异常音管标记和单次维护报告页。

在占位页基础上补成了**可追溯的调音账**，核心规则：

- **读数绑定证书**：每条读数记录绑定的校准证书版本与截止时间，随证书资格实时判定可用性。
- **待核验队列**：证书失效或来源不明的读数自动进入待核验，报告一律不采用。
- **换证即重算**：提交新证书后旧证书立即失效，相关音管结论基于已核验集合立即重算；绑定旧证书的已签发报告退回复核，全程留痕（报告历史 + 审计日志）。
- **版本冲突**：两人同时提交仪器更新时按乐观并发校验，后到者收到 409 版本冲突，可同步对方版本后重新编号提交，或放弃本地更新。
- **失败保留与续传**：证书保存失败时已核验内容保留在本地（localStorage），未完成的提交单独落账，恢复后只续传该提交。

页面提供演示按钮：模拟保存失败、模拟同事并发提交、重置演示数据。
